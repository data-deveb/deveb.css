## Quick Installation
Add the production stylesheet into your HTML <head> tag. No package manager or build tool required.

```html
<!-- Include deveb.css -->
<link rel="stylesheet" href="/assets/css/deveb.css">
```
## How deveb.css Works
- **Semantic HTML First:** Write standard HTML tags (<article>, <section>, <header>, <footer>, <nav>). Styles automatically apply without utility class overload.

- **Fractional Ratios:** Layouts rely on clean mathematical proportions rather than rigid column clamps.

- **Native Responsiveness:** Built-in CSS rules adapt to any screen size without requiring custom JS listeners.
